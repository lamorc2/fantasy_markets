## Fantasy Markets

# Overview

This is a project for a multiplayer fantasy sports experience with a new twist. You aren't trading sports players, you're trading the NYSE. 
Invite friends, and each of you can manage your own hedge fund. Set a name, a logo and an acronym.
Depending on the format of your league, each fund manager will get a set number of starting funds each week OR for a better challenge, one fund for the entire season. 

- Daytrading (H2H Mode): Week to Week, each manager gets X dollars to spend. From Monday to Friday, you will get in market times accessibility to make trades corresponding to real market values. At the end of the week, the manager with the highest net value will win.

- Quarterly/Yearly: For the diehards who want to be able to hold long positions, quarterly/yearly mode will rank your league in net value over a set time period.
